# Dental Chair Display — Premium Stable 5.2.0

هذه النسخة مبنية فوق واجهة `2.4.0-clinic-ui` المعتمدة، مع إضافة مزامنة Controller 2.7 وعرض الخطة القصصي من دون استبدال الهوية البصرية.

## الميزات الموجودة
- الواجهة المعتمدة لشاشة العيادة: هادئة، داكنة ومتجاوبة مع 1280×1024 و16:9.
- الوضع الداكن والفاتح والتلقائي من الكونترولر مع تطبيقه عند كل إعادة اتصال.
- تباين أعلى وحدود أوضح بين بطاقات الوضع الفاتح.
- خط IBM Plex Sans Arabic نفسه المعتمد في البرنامج الرئيسي.
- اكتشاف الكونترولر تلقائيًا عبر UDP ثم فحص الشبكة المحلية.
- شاشة الترحيب الرئيسية.
- استقبال اسم المريض والطبيب ورقم الجلسة تلقائياً.
- ترحيب المريض مدمج في الشاشة الرئيسية من دون شاشة مريض منفصلة.
- استقبال جنس المريض لاختيار «سيد/سيدة»، مع إبقاء المرضى القدامى بلا تخمين.
- الاسم الأول للترحيب والاسم الكامل داخل خطة العلاج.
- بروتوكول محلي 3 مع ACK وإعادة الاتصال واستعادة آخر شاشة.
- اتصال WebSocket ثابت بلا مهلة قراءة قصيرة، مع إبقاء فحص الشبكة المتوازي السريع.
- التنقل بالريموت بين Home وQR، والتحكم بعرض الخطة يميناً ويساراً.
- فتح تطبيق DTDC GAMES المستقل وإغلاقه عند الانتقال إلى محتوى آخر.
- عرض SOPRO والصور والبانوراما داخل إطار مقصوص يمنع تغطية الهوامش والعناوين.
- تكبير وتصغير وتحريك وتدوير الصورة 20 درجة.
- GIF علاجي متحرك مع حفظ محلي ثابت بعد أول تحميل وتحديث تلقائي عند تبديل الملف.
- إضاءة خلفية متحركة بحواف متلاشية وناعمة.
- فيديو وPDF.
- QR موعد خام من نوع VEVENT وبأقل بيانات، مع توضيح تنبيه التقويم القابل للضبط من الكونترولر.
- بحث شبكي متوازٍ أسرع مع الاحتفاظ باكتشاف UDP والاتصال المحفوظ.
- عرض خطة قصصي: بانوراما فقط، ثم تراكم مجموعات الرسم، ثم شاشة مستقلة لكل مرحلة، ثم خاتمة خضراء مع الوقت والتكلفة الإجمالية.
- خلفية متحركة ببطء وصورة توضيحية مستقلة لكل مرحلة.
- لا تظهر أزرار أو تعليمات فوق بانوراما المريض؛ يظهر رقم المجموعة فقط.
- أيقونة تطبيق Android TV.

## البناء
GitHub Actions لا يعتمد على `gradle-wrapper.jar`.
يقوم بتثبيت Java 17 وGradle 8.11.1 ثم يبني من الصفر.

تتضمن الحزمة أيضاً Gradle Wrapper حقيقياً وكاملاً للاستخدام المحلي، وليس الملفات النصية الناقصة التي سببت خطأ:
`chmod: cannot access 'gradlew'`.

اسم Artifact المتوقع:
`DTDC-DISPLAY-PREMIUM-APK`

لم يعد يظهر أي نص إصدار داخل واجهة المريض.

تم تنفيذ بناء محلي كامل للإصدار نفسه باستخدام JDK 17 وGradle 8.11.1 وAndroid SDK 35، وانتهت مهام
`compileDebugKotlin` و`packageDebug` و`assembleDebug` بنجاح.

## الرفع
ارفع محتويات هذا المجلد مباشرة إلى جذر مستودع:
`Dental-Chair-Display`

يجب أن يظهر في الجذر مباشرة:
- app/
- gradle/
- .github/
- build.gradle.kts
- settings.gradle.kts
- gradle.properties

لا تترك Workflow قديماً بجانب الملف الجديد داخل `.github/workflows`، ولا تستخدم خطوة `chmod +x gradlew`.
