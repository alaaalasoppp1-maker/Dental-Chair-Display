# Dental Chair Display — Stable 5.1.0

مستودع Android TV كامل لتطبيق شاشة كرسي Dental Chain.

## الميزات الموجودة
- واجهة Dental Chain الحديثة مع هوية العيادة القابلة للتعديل من الكونترولر.
- الوضع الداكن والفاتح من الكونترولر.
- اكتشاف الكونترولر تلقائيًا عبر UDP ثم فحص الشبكة المحلية.
- شاشة الترحيب الرئيسية.
- استقبال الاسم الأول للترحيب والاسم الكامل للخطة، مع لقب سيد/سيدة دون تخمين جنس المرضى القدامى.
- بروتوكول محلي 3 مع تأكيد الاستلام وإعادة إرسال آخر شاشة بعد إعادة الاتصال.
- التنقل بالريموت يمينًا ويسارًا بين Home وPatient وServices وQR وGame.
- فتح تطبيق DTDC GAMES المستقل وإغلاقه تلقائياً عند إرسال محتوى جديد.
- عرض SOPRO والصور والبانوراما.
- تكبير وتصغير وتحريك وتدوير الصورة 20 درجة.
- GIF علاجي مع حفظ محلي بعد أول تحميل.
- فيديو وPDF.
- QR الموعد مع تنبيه قبل 24 ساعة.
- عرض خطة قصصي: بانوراما، تراكم مجموعات الرسم، شاشات المراحل، ثم النتيجة النهائية باللون الأخضر.
- محاذاة الرسومات مع أبعاد البانوراما، وخلفية متحركة ببطء لكل مرحلة.
- أيقونة تطبيق Android TV.

## البناء
GitHub Actions لا يعتمد على `gradle-wrapper.jar`.
يقوم بتثبيت Java 17 وGradle 8.11.1، ثم يبني المشروع باستخدام Android SDK المتاح على GitHub.

الإصدار في `app/build.gradle.kts` هو `5.1.0`.

## الرفع
ارفع محتويات هذا المجلد مباشرة إلى جذر مستودع:
`Dental-Chair-Display`

يجب أن يظهر في الجذر مباشرة:
- app/
- gradle/
- .github/
- build.gradle.kts
- settings.gradle.kts
- gradle.properties

لا تعتمد الحزمة على ملف `gradle-wrapper.jar`؛ للبناء المحلي استخدم Android Studio، أو ارفع المشروع إلى GitHub وشغّل Workflow المرفق.
